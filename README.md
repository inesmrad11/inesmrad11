## Featured Projects

### VMware Governance Platform *(Internship Project — Ooredoo)*

Cloud-native platform for VMware infrastructure governance, designed to improve capacity management, detect inefficiencies, and automate remediation in virtualized environments.

The system implements a FinOps/SRE-inspired approach to infrastructure optimization by combining real-time telemetry, analytics, and controlled automation.

It enables infrastructure teams to move from reactive management to proactive capacity planning and governance.

**Core Features:**
- VMware vCenter integration for infrastructure telemetry collection
- Resource optimization analysis (CPU, memory, storage utilization)
- Detection of inefficiencies (VM sprawl, zombie workloads, oversized VMs)
- Capacity forecasting and planning insights
- Rule-based recommendation engine
- Human-in-the-loop remediation workflows
- Kubernetes-based microservices architecture
- Observability dashboards for infrastructure insights

**Tech Stack:** FastAPI, Python, React, PostgreSQL, VMware vSphere/vCenter, Kubernetes, Docker, Prometheus, Grafana
